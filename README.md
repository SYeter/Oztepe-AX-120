# PyQt5 Demo Arayüzü

Bu proje, paylaştığınız görsele benzer bir **PyQt5 widget demo arayüzü** üretir.

## İçerik
Arayüzde aşağıdaki bölümler bulunur:
- Üst bar: stil seçimi, standard palette, disable widgets
- Group 1: radio button'lar + tri-state check box
- Group 2: default/toggle/flat push button
- Alt sol: Table + Text Edit sekmeleri
- Alt sağ (Group 3): password input, spin box, datetime edit, slider, dial, scrollbar
- En altta progress bar (%27)

## Kurulum
```bash
pip install -r requirements.txt
```

## Çalıştırma
```bash
python app.py
```
